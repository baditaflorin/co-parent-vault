# co-parent-vault

[Live GitHub Pages app](https://baditaflorin.github.io/co-parent-vault/)

Private local-first co-parenting tools for calendars, expenses, documents, and communication archives.

## Quickstart

```bash
npm install
make dev
make test
make build
make pages-preview
```

## Architecture

This is a Mode A GitHub Pages app. Sensitive family data stays in the browser, encrypted with a user passphrase, and portable sharing happens through encrypted files and invite payloads.
