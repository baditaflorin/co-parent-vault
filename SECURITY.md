# Security Policy

Please report security issues privately through GitHub security advisories:

https://github.com/baditaflorin/co-parent-vault/security/advisories/new

A disclosure email is not configured yet; add one here before directing reporters to email.

Do not include real custody, child, parent, payment, or court data in public issues.

## Scope

`co-parent-vault` is a local-first browser app. The project does not operate a hosted backend for user data. Security reports should focus on client-side data exposure, cryptographic misuse, unsafe dependencies, or build/deployment issues.
