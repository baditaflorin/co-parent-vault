# Privacy

`co-parent-vault` does not run a hosted data backend and does not include analytics in v1.

Data entered in the app is stored in the browser as an encrypted IndexedDB vault. The passphrase is not sent to the project, GitHub, or PayPal. Encrypted exports and sealed event invites are files or text payloads that users choose to share.

Optional local LLM calls use an endpoint typed by the user, intended for localhost services such as an Ollama-compatible API. The app does not ship API keys.
